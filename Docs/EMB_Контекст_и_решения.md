# EMB — Контекст и решения

> [!info] Назначение
> Краткая **память проекта**, а не дополнительный регламент. Здесь фиксируются текущие решения, проверенные факты и вопросы для исследования. **Любое решение можно пересмотреть** при появлении более качественного способа. Не превращать список кандидатов в утверждённый стек.

**Действующий регламент:** утверждённые инструкции проекта ChatGPT **v4.2**; AGENTS.md — практические инструкции для работы в репозитории, README.md — обзор. Этот журнал даёт контекст и не ограничивает исследования. Прежние Guidelines не являются действующими правилами и не восстанавливаются. `EMB_Project_Instructions_v4.1.txt` — сохранённая предыдущая редакция; без отдельного согласования не удалять и не переписывать. Технические утверждения сверять с актуальными первичными источниками и результатами проверок на текущей версии Workbench; существенные расхождения отмечать явно.

## 1. Состояние на 08.11.2026

- **Цель:** бесплатные, качественные и воспроизводимые карты для Arma Reforger; перенос на Arma 4 оценивать отдельно.
- **Стадия:** A–B, исследование ↔ малые проверки. Сквозной рабочий процесс создания полноценного Synthetic-мира **ещё не подтверждён**.
- **Synthetic:** приоритет; оригинальные миры с учётом игрового процесса, художественная и Level Design-доработка — за человеком.
- **RealWorld:** отдельное направление. Ruhnu сохранён и не определяет инструменты Synthetic.
- **Архитектура:** EMB не обязан быть приложением, генератором или фиксированным набором модулей.
- **Репозиторий:** `main`, HEAD и локальная ссылка `origin/main` указывают на `a8262d4` на момент ревизии; удалённое состояние без fetch не проверялось. До правок отслеживаемые файлы не имели изменений. Неотслеживаемые файлы: этот журнал, `Docs/EMB_Project_Instructions_v4.1.txt` и четыре JSON-файла `.obsidian/`. Они находятся в рабочей папке, но ещё не включены в Git.

- **Растительность и оформление:** штатные FG/PG/Forest Generators; Terrain Automation Tools и Advanced Terrain Tools — кандидаты для отдельной проверки совместимости и пользы.
- **Автоматизация:** Goldwep MCP установлен, но новые операции и совместимость с 1.9 не считать проверенными.
- **RealWorld:** Base Map Generator NG — кандидат; решение для Ruhnu не утверждено.
- **Дополнительные идеи из обзора ноября 2026:** Terrain Lab, Procedural Terrains, специализированные инструменты военного оформления. Это обзор кандидатов, не результаты практических тестов; источники и точные версии здесь не записаны. Наличие и заявленная функциональность не равны пригодности для рабочего процесса.

## 5. Ближайшая задача — выбор, не обязательство

**Выяснить, какой бесплатный способ даёт лучший исходный Synthetic-рельеф, пригодный для игры и редактирования в Reforger.**

Минимальная проверка одного перспективного варианта: создать небольшой характерный остров → сохранить исходный проект/параметры → экспортировать heightmap и доступные маски → импортировать штатными средствами → оценить берег, уклоны, масштаб, уровень моря и ручную доработку.

Если результат не устроит — вернуться к поиску и сравнить альтернативы. Не разрабатывать собственный генератор или импортёр ради исправления неудобств одного кандидата.

## 6. Как обновлять журнал

- **После значимого решения:** обновить 1–3 строки в разделе 2; коротко указать *что*, *почему*, *чем подтверждено* и *когда пересмотреть*.
- **После проверки:** перенести только подтверждённый результат в раздел 3, а ограничения — в раздел 4.
- **При смене направления:** поправить текущую запись; если важно понять историю, оставить одну строку «Пересмотрено: дата, причина». Не хранить подробный архив неудачных попыток.
- **Регулярно сокращать:** верхняя часть должна оставаться читаемой за 2–3 минуты.
- **При конфликте:** этот журнал уступает актуальным инструкциям и проверенным фактам.

## 7. Как сохранять контекст ChatGPT

**Obsidian-файл на компьютере не синхронизируется с ChatGPT автоматически.** После существенных изменений загрузить его обновлённую версию в файлы проекта ChatGPT (заменив прежнюю, если она там есть) или прикрепить в рабочий чат. Не держать две независимо редактируемые копии.

При возобновлении обсуждения достаточно написать: «Продолжаем EMB. Используй актуальные инструкции проекта и файл „EMB — Контекст и решения“; кандидатов не считай утверждёнными».
