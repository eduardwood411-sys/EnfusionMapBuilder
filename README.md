# Enfusion Map Builder

Модульная система полуавтоматического создания игровых миров для Enfusion.

## Основное направление

Генерация оригинальных синтетических карт по seed и параметрам.

Основной конвейер:
Procedural Source -> WorldModel -> Core -> Validation -> Game Adapter

## Вторичное направление

Создание карт на основе реальных DEM, GIS, OSM, ортофото и других геоданных.
Ruhnu используется как реальный производственный и тестовый проект.

## Принцип разработки

Сначала искать и проверять готовые решения.
Интегрировать и расширять существующие инструменты.
Писать собственные компоненты только при необходимости.

## Первый MVP

Seed + параметры -> рельеф -> берег -> гидрология -> базовые биомы -> воспроизводимый Output
